# צילומי מסך לפרויקטים

שימו כאן את התמונות של הפרויקטים:

```
project-1.png
project-2.png
project-3.png   (אופציונלי)
project-4.png   (אופציונלי)
```

> `project-2.png` הוא צילום מסך של הדמו החי `demos/crm-finauto.html` (רוחב 1750px, זום 80%).
> אם משנים את הדמו — כדאי לצלם אותו מחדש כדי שהתמונה בכרטיס תישאר תואמת.

## המלצות לצילום

| נושא | המלצה |
|---|---|
| יחס | 16:10 (למשל 1600×1000) |
| פורמט | PNG לצילומי מסך, JPG לתמונות |
| משקל | עד ~300KB לתמונה |
| תוכן | **טשטשו נתונים אמיתיים של לקוחות** — שמות, טלפונים, סכומים |

## איך מחליפים את ה-placeholder

בקובץ `index.html`, בתוך סקשן הפרויקטים, מחליפים את הבלוק:

```html
<div class="project__placeholder"> ... </div>
```

בתמונה:

```html
<img src="assets/projects/project-1.png"
     alt="מסך ניהול לקוחות במערכת שנבנתה"
     loading="lazy" width="1600" height="1000">
```

**חשוב:** ה-`alt` צריך לתאר מה רואים במסך — זה נדרש לנגישות ולקידום.
